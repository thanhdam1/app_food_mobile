# 🖥️ Backend API Service (`feat/be-api`)

Thư mục dành riêng cho bạn đảm nhiệm vị trí **Backend Developer**.

## Nhiệm vụ chính:
1. Xây dựng dịch vụ RESTful API phục vụ ứng dụng Mobile:
   - **Xác thực (Auth):** Đăng ký, đăng nhập, JWT token, lấy thông tin cá nhân.
   - **Món ăn & Danh mục (Foods & Categories):** Lấy danh sách món, chi tiết món, lọc theo thể loại.
   - **Đơn hàng (Orders):** Tạo đơn hàng, xem lịch sử đơn, cập nhật trạng thái đơn.
2. Xuất tài liệu API (Swagger UI hoặc Postman Collection) để bạn `feat/fe-android` tích hợp.

## Đề xuất công nghệ:
- Node.js (Express / NestJS) hoặc Python (FastAPI) hoặc Java (Spring Boot).
- Đặt toàn bộ mã nguồn backend vào trong thư mục này.
