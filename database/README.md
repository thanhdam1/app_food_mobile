# 🗄️ Database & AI Module (`feat/database`)

Thư mục dành riêng cho bạn đảm nhiệm vị trí **Data & AI**.

## Nhiệm vụ chính:
1. **Thiết kế CSDL (Database Schema):**
   - Lập sơ đồ quan hệ thực thể (ERD).
   - Thiết kế các bảng: `users`, `categories`, `foods`, `orders`, `order_items`, `reviews`.
   - Viết file script tạo bảng (`schema.sql` hoặc Migration script).
2. **Dữ liệu mẫu (Seed Data):**
   - Chuẩn bị dữ liệu mẫu (`seed_data.sql` hoặc `data.json`): tên món, mô tả, giá, link ảnh, calo.
3. **Tích hợp Trí tuệ nhân tạo (Gemini AI):**
   - Thiết kế prompt mẫu cho tính năng: Gợi ý món ăn theo tâm trạng, tính toán lượng calo, hoặc hỏi đáp thực đơn.
