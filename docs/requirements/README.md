# 📋 Đặc Tả Yêu Cầu & Thiết Kế UI/UX (`docs/requirement`)

Thư mục dành riêng cho bạn đảm nhiệm vị trí **Business Analyst (Requirement)**.

## Nhiệm vụ chính:
1. **Phân tích yêu cầu:**
   - Xác định phạm vi và danh sách tính năng chính của app.
   - Viết tài liệu đặc tả yêu cầu phần mềm (SRS).
   - Danh sách User Stories (Dạng: "Là một [người dùng], tôi muốn [chức năng] để [lợi ích]").
   - Vẽ biểu đồ Use Case, Activity Diagram (sơ đồ luồng đặt hàng).
2. **Thiết kế giao diện (UI/UX Mockup):**
   - Thiết kế giao diện khung xương (Wireframe) hoặc hoàn chỉnh trên **Figma**.
   - Cung cấp link Figma hoặc ảnh xuất giao diện vào thư mục này để bạn `feat/fe-android` nhìn vào code.
